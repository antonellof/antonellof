## Notable Projects:

- **[Frink](https://github.com/antonellof/frink)** [![Crates.io](https://img.shields.io/crates/v/frink-inference.svg)](https://crates.io/crates/frink-inference) - Pure-Rust GGUF inference engine meant to replace llama.cpp: same models and commands, quantized CPU, Apple Metal and CUDA kernels, MoE support, and an OpenAI-compatible server in one binary. 100 architectures verified against llama.cpp's own logits, with every speed claim benchmarked on the same host and file. Write-ups: *[the Rust alternative to llama.cpp](https://www.fratepietro.com/2026/frink-rust-alternative-to-llama-cpp/)* and *[Frink on Metal, at parity with llama.cpp and past it](https://www.fratepietro.com/2026/frink-metal-parity-llama-cpp/)*.

- **[GPUlayer](https://github.com/antonellof/gpulayer)** [![PyPI](https://img.shields.io/pypi/v/gpulayer.svg)](https://pypi.org/project/gpulayer/) - One layer between your code and every GPU you can reach: your laptop, servers that join with `gpulayer join`, Kubernetes pools, or cloud VMs created per job. Runs commands, Python functions, multi-node PyTorch training and long-running services on one queue, verifies each worker's CUDA/MPS/MLX stack before placing work, explains why a job can't be placed, and exposes it all to coding agents (Claude Code, Pi, MCP). Docs: *[gpulayer.dev](https://www.gpulayer.dev/)*.

- **[LASA](https://github.com/antonellof/lineage-attack-surface-analyzer)** - Lineage Attack Surface Analyzer, a defensive research harness that asks whether jailbreak evidence from an open-weight base model can predict which fine-tuned derivatives inherit the same weaknesses. Attacks are searched only on the source model, frozen, then measured on related checkpoints against attack-free, random-suffix and mismatched-suffix controls, with a committed study plan and an independent HarmBench classifier. Paper: *[preprint (PDF)](https://github.com/antonellof/lineage-attack-surface-analyzer/blob/main/paper/PAPER.pdf)*.

- **[gitgui](https://github.com/antonellof/gitgui)** - A git GUI that runs inside the terminal, next to your coding agent. One Rust binary paints an iced interface as pixels into a cmux, Ghostty or kitty pane over the kitty graphics protocol, or opens a desktop window where the terminal has no graphics: commit graph, staging by file, hunk or line, a three-way conflict resolver, history rewriting, a built-in editor, draggable panes, and a socket so agents like Pi drive it. Write-up: *[gitgui: a real git GUI inside cmux, next to Pi](https://www.fratepietro.com/2026/gitgui-terminal-git-gui-cmux-pi/)*.

- **[VittoriaDB](https://github.com/antonellof/VittoriaDB)** - Zero-configuration embedded vector database with HNSW indexing, ACID storage, and REST API. Single Go binary for local AI development.

- **[PeerClaw](https://github.com/antonellof/peerclaw)** - Decentralized P2P AI agent network in a single static binary. BitTorrent shape applied to inference: peers share compute, agents earn and spend tokens for it.

- **[DistX](https://github.com/antonellof/DistX)** - Vector database written in Rust, with SIMD-optimized HNSW indexing, a Qdrant-compatible REST API, and gRPC.

- **[s0-cli](https://github.com/antonellof/s0-cli)** - LLM-driven CLI agent that finds security vulnerabilities and AI-slop patterns: stub auth, hallucinated imports, dummy crypto, prompt-injection sinks. Hybrid of classic scanners (semgrep, bandit, gitleaks, trivy) with LLM triage on top, plus a self-optimizing meta-harness loop. Write-up: *[the meta-harness that tunes its own scanner](https://www.fratepietro.com/2026/s0-cli-meta-harness-security-scanner/)*.

- **[Cognitora inference](https://github.com/antonellof/cognitora-inference)** - Open-source, datacenter-scale LLM orchestration above vLLM, SGLang, TensorRT-LLM, and llama.cpp: KV-aware routing, prefill/decode disaggregation, multi-tier KV cache, static Rust binaries for bare metal, Kubernetes, or cloud. Write-ups: *[the orchestrator](https://www.fratepietro.com/2026/cognitora-inference-llm-orchestration/)* and *[admission control for distributed LLM inference](https://www.fratepietro.com/2026/llm-admission-control-distributed-inference/)*.

- **[Rondine](https://github.com/antonellof/rondine)** 🐦 - Hardware-aware local LLM launcher. Detects the machine, picks a model that fits, and applies tuned configs for Mac, NVIDIA GPUs and DGX Spark instead of leaving you to do flag archaeology. Write-up: *[Rondine: hardware-aware local LLM serving](https://www.fratepietro.com/2026/rondine-hardware-aware-local-llm-launcher/)*.

- **[MARS](https://github.com/antonellof/MARS)** - GPU-resident multimodal memory substrate for real-time embodied AI. Episode-scoped retrieval as a CUDA kernel-level primitive: 197 µs p99 at N=1M with perfect cross-modal `hit@15`, 33× faster than FAISS-Flat-GPU on the same hardware. Companion paper: *[MARS: Episode-Scoped GPU Retrieval for Real-Time Embodied AI](https://www.fratepietro.com/papers/MARS/main.pdf)*.
